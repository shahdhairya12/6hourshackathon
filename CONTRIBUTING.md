# Contributing to PULSE

We welcome contributions to PULSE! Follow these steps to ensure smooth collaboration:

## Development Workflow

1. Fork and clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Verify code quality and run the unit test suite:
   ```bash
   npm test
   npm run build
   ```

## Commit Conventions

Use Conventional Commits:
- `feat: add new savings goal milestone animation`
- `fix: correct daily allowance division on Day 30`
- `docs: update mathematical formula explanations in README`
- `test: add unit tests for emergency fund cushion calculations`
