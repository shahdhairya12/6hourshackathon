## Local-First Data Privacy

PULSE operates strictly on a **local-first client architecture**:
- Financial data, simulation runs, transactions, and personas remain exclusively in the user's browser via LocalStorage.
- No external analytics trackers or third-party tracking scripts are embedded.
- Synthesized Web Audio API effects run locally without downloading remote audio streams.
